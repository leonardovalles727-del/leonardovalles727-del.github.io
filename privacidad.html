Política de privacidad

La aplicación administra el canal Curiosidades Sin Límites por cuenta de su titular. Usa el acceso autorizado de Google para consultar estadísticas y subir videos a YouTube.

Datos y almacenamiento

Las estadísticas se usan para evaluar el canal. Las credenciales se guardan en archivos locales del titular y en un secreto de GitHub Actions del repositorio privado. Los servicios de Google y GitHub procesan los datos necesarios para ejecutar esas operaciones. La información obtenida de Google no se vende ni se utiliza para publicidad. El sitio informativo no solicita credenciales.

Revocación y eliminación

El titular puede revocar el permiso en Conexiones de Google y eliminar los archivos locales y el secreto de GitHub. Las pruebas de video en GitHub usan archivos con retención de tres días.
